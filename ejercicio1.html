Ejercicio 1: Verificación de Asistencia

Este ejercicio permite verificar si un aprendiz específico se encuentra en una lista de asistencia.

Resultado:

Explicación Técnica

Entradas:

  • Lista de Aprendices
  • Nombre a Buscar

Proceso:

  1. Conversión a arreglo de nombres.
  2. Normalización de nombres para comparación.
  3. Verificación de existencia.

Salidas:

  • Mensaje de presencia/ausencia.

Reglas de Negocio:

  • Búsqueda insensible a mayúsculas/minúsculas.
  • Ignora espacios iniciales/finales.
  • Nombres separados por comas.

Casos Límite:

  • Lista vacía.
  • Nombre a buscar vacío.
  • Nombres con solo espacios.

Decisiones de Diseño Justificadas:

  1. Normalización de Entradas.
  2. Uso de `includes()` para verificación.
