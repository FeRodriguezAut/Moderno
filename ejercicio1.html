Ejercicio 1: Verificación de Asistencia

Este ejercicio permite verificar si un aprendiz específico se encuentra en una lista de asistencia.

Resultado:

Explicación Técnica

Entradas:

  • Lista de Aprendices: Una cadena de texto donde los nombres de los aprendices están separados por comas (e.g., "Ana, Juan, Pedro").
  • Nombre a Buscar: Una cadena de texto que representa el nombre del aprendiz que se quiere verificar.

Proceso:

  1. La lista de aprendices ingresada se convierte en un arreglo de nombres.
  2. Tanto los nombres de la lista como el nombre a buscar se "normalizan" (se eliminan espacios extra y se convierten a minúsculas) para asegurar una comparación sin errores de formato.
  3. Se verifica si el nombre normalizado a buscar existe dentro de la lista de nombres normalizados.

Salidas:

  • Un mensaje indicando si el aprendiz está presente o no está presente en la lista, mostrado en la sección de resultados.

Reglas de Negocio:

  • La búsqueda no distingue entre mayúsculas y minúsculas (ej: "juan" es igual a "Juan").
  • Los espacios al inicio o al final de los nombres se ignoran (ej: " Juan " es igual a "Juan").
  • Los nombres en la lista deben estar separados por comas.

Casos Límite:

  • Lista vacía: Si no se ingresa ningún aprendiz, siempre indicará que el nombre no está presente.
  • Nombre a buscar vacío: Si no se ingresa un nombre a buscar, siempre indicará que no está presente.
  • Nombres con solo espacios: Si un nombre en la lista es " " o el nombre a buscar es " ", se tratará como un nombre vacío y no se encontrará.

Decisiones de Diseño Justificadas:

  1. Normalización de Entradas (`trim()` y `toLowerCase()`):

    Por qué se usó: Se normalizan tanto el nombre a buscar como los nombres en la lista para evitar errores de validación por mayúsculas/minúsculas o espacios en blanco accidentales. Esto hace la búsqueda más robusta y amigable para el usuario.

  2. Uso del método `includes()` para la verificación:

    Por qué se usó: Para este caso, solo necesitamos saber si el elemento existe (un booleano), no su posición o el elemento en sí. `includes()` es el método más directo y legible para esta tarea, en comparación con `find()` (que devolvería el elemento) o `filter()` (que crearía un nuevo arreglo). Su rendimiento es óptimo para una simple comprobación de existencia.
